Design system · v1

Style guide

The building blocks behind every page. Tokens map one-to-one to Tailwind v4 @theme variables, and components map to the existing components/ui primitives.

01 · Logo

Logo usage

Keep the existing wordmark. Use black on light backgrounds and white on dark. Minimum height 22px on screen.

02 · Colour

Colour palette

08 · Motion

Motion system

Motion explains and reassures. It is not decoration. Presets match lib/motion/presets.ts (motion/react), smooth scrolling uses Lenis like the app, and everything switches off when a visitor prefers reduced motion.

fadeUp
y 24px → 0 · 600ms · ease-out-expo
stagger
children 100ms apart
scaleIn
scale .95 → 1 · 400ms
slideDown
y −8px → 0 · 250ms (menus)
Easingease-out cubic-bezier(.16,1,.3,1) for entrances · ease-in-out (.65,0,.35,1) for lines & loops · spring (.34,1.56,.64,1) for small pops
Durations150 · 250 · 400 · 600 · 900ms. UI feedback ≤ 250ms, entrances 400–600ms, data loops 2–8s.
RulesAnimate once on scroll. Loops run only while on screen. Never block reading or input. Respect reduced motion.
Every sectionScroll reveal: fadeUp / scaleIn with 100ms staggerGuides the eye through each section in order
